# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** in this repository
(<https://github.com/Styx85/proxmox-reboot-update/security/advisories/new>).

Please include the affected version, a description of the issue, and steps to reproduce it. You will receive a response as soon as possible.
